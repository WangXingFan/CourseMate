# 信号与系统课程内容包

课程以用户提供的《信号与系统_总知识点总结.md》为原稿；发布讲义移除第 0、4、6、7 章，保留 **52 个小节**。原第 5 章展示为第 4 章，知识点 ID 继续使用 `ss-5-*` 以保持历史链接稳定。每节各有一道课前预习、课中练习、课后巩固题，共 **156 道**。附录 C 没有独立小节，保留在 B.10 讲义末尾。题目为本项目编写的练习，并非教材原题或历年真题。

- `source.md`：保留原稿，不覆盖用户原文件。
- `notes.md`：生成的校订版总讲义。
- `corrections.json`：26 条逐项修订记录。另统一修正了附录 C 的采样边界与稳定性条件，以及原稿资料来源的说明。
- `questions.mjs`：服务端题库的编写源文件，含参考答案与解析，不可复制到前端静态资源。
- `knowledge-base/*.md`：52 份按知识点拆分的知识库导入文件，含稳定 ID、版本、章节和课程内链接。
- `backend/internal/domain/learning/content/course.json`：生成的课程页面数据，不是知识库上传文件。

## 如何导入知识库

课程页面 `/learn/knowledge` 直接读取后端内置版本，不需要先建立向量库。登录后可按章节检索讲义、查看公式并完成阶段练习。

知识库需要管理员手动创建并上传资料。要在对话中检索本课程内容，请创建“信号与系统”知识库，并上传 `knowledge-base/*.md` 中的 52 份拆分讲义；可分批上传。配置 Embedding 后，等待自动向量化完成，或在后台知识库资料中批量提交向量化，再在对话中选择该知识库。

默认允许的文档格式包括纯文本与 Markdown（`.txt`、`.md`）、PDF、Word（`.doc`、`.docx`）、Excel（`.xls`、`.xlsx`）、CSV，以及 JSON、YAML、TOML 等文本格式；实际可上传格式受管理员 MIME 白名单限制。PowerPoint 默认不在白名单中。图片需要 OCR 或支持图片的多模态 Embedding 才能用于检索，视频不会建立知识库检索索引。课程讲义优先使用 `.md`，章节标题、公式和段落结构更容易保留。扫描版 PDF 需要可用的 OCR 服务；加密或损坏文件无法正常提取。

上传后等待资料解析与向量索引完成，再在对话中选择该知识库。可用问题“单位矩形与两倍宽矩形卷积为何出现平顶？”测试，并检查引用的小节是否为 `ss-2-5` 或 `ss-2-6`。

只上传拆分后的校订文件，避免原稿、总讲义与拆分讲义同时入库造成重复召回。不要上传含答案的 `questions.mjs` 或后端 `course.json`。手动更新时按稳定知识点 ID 替换旧版本。实验助教当前仍使用既有引用白名单，知识库不会使它自动变成全文检索助教。

## 题目与公式输入

预习用于激活概念；课中用于公式应用和关键步骤；课后用于迁移、综合或易错点辨析。每个小节当前每阶段一题，之后可按授课计划将多个小节组合成一次课，也可继续扩充同阶段题量。

计算题采用数值、分数、多个系数和分段函数填空。例如输入 `9/4`，或在矩形卷积中分别填写上升段系数、平顶值、下降段系数。输入实时显示公式预览；字段按给定单位填写。服务端只解析小数、科学计数法或一个数值分数，默认误差为 `1e-6 × max(1, |参考值|)`，各空独立计分。无法解析的输入不会记作数学答错。

题目答案与解析仅由服务端在提交后返回。作答按账号保存，网络中断后重试沿用原 UUID 和答案，修改同一 UUID 的内容返回 409。重新练习会创建新记录，目录进度依据最新一次作答；页面同时区分“已作答阶段”和“最新作答全对阶段”。这是一套自学反馈机制，不是防作弊考试系统。

当前不支持任意符号等价判断、完整推导自动评分、手写照片识别或图片判卷。下一阶段可接入公式编辑器、人工/自评推导与图片附件；应保留逐步评分和无法判断状态，不能将识别失败计为数学错误。

## 维护

编辑原稿或 `questions.mjs` 后运行 `node scripts/generate-signals-content.mjs`，同步提交生成的讲义、拆分文件和后端内置 JSON。修改题意、答案或评分规则时升级题目 ID 与课程版本，旧记录仍保存原始评分快照。Go 测试、公式渲染检查和生成一致性检查在 GitHub Actions 执行。

这些资料经过项目级公式与条件校订，但未逐页核对教材与所有课件。特别注意因果性、BIBO 与内部稳定、采样边界、单边/双边变换及初终值定理的适用条件。
