# 成绩登记表模板

`grade-registers.xlsx` 从教师提供的 2025–2026 学年第二学期、CS3017《信号与系统》24电子1班的 2.4 归档表提取版式。只保留表头、格式和一行空白学生行；历史学生、学号、分数、教师、学期、学院、教室、公式和文档个人属性均已清除。原 `.xls` 考勤、课堂表现表已转换为 `.xlsx`。

归档分类使用 CourseMate 的作业、实验、考勤、课堂成绩和 AI 活跃度；AI 表沿用原简单成绩表版式，不包含课前视频项目。各表保留宋体、合并结构、黑色细边框和 A4 版式，行高适当增加以容纳课程信息和规则。第 2、3 行保留两行表头：学年学期、课程代码、课程名称；教师姓名、所属学院、上课教室。六项信息由教师在导出中心填写并按班级保存，生成时读入；教学班和学生数据由当前导出范围填写。

运行时只依赖 Go 和内嵌工作簿，不读取教师本机归档目录，也不依赖 Office。修改模板时保留当前工作表名和空白数据行位置：总表、作业、实验从第 8 行开始，其他表从第 6 行开始。
