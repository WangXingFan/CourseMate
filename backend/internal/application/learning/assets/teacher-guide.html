一、开课前：选择班级并开启指定实验

  1. 打开学校提供的 CourseMate 正式网址，使用教师账号登录，进入左侧“班级”。学生访问同一网址，使用自己的学生账号登录；页面按账号角色显示功能。
  2. 选择本次授课的班级。若尚无班级，点击创建班级，名称可填“信号与系统实验班”，保存后选中它。
  3. 在“学生”页签检查名单。已有学生账号使用“添加学生”；尚无账号使用“创建学生”或“导入学生”。确认学生属于当前班级。
  4. 在班级上方“实验开放”区域找到“实验一”，将开关切到开启。本节只做实验一时，实验二、实验三保持关闭。实验二、三上课时分别开启对应开关，三个开关互不联动。
  5. 教师打开L1-1工作台作演示。教师可预览全部实验；学生是否能进入，以班级开关为准。
  6. 学生登录自己的账号，进入“实验”，打开已开启的实验。核对姓名与班级，确认保存状态正常。教师演示练习不产生学生正式成绩；教师样题见本页“发布与验收”。

二、所有任务共用的操作方法

L1-2 使用“发送脉冲 → 观察输出 → 辨识黑箱”；L1-3 使用“诊断 → 选测试 → 预测 → 提交验证”；L1-4 使用“看干扰 → 保住 R 波 → 跟着窗口走”。这三项按下方各自任务说明操作，其他任务按以下流程操作。

  1. 打开具体任务后，先看“本项目标”和给定原信号。在“先判断”文本框写一句判断，点击“开始操作”。预测不计分，不需要准确猜中。
  2. 进入“做对照”，左上“当前对照”显示“1 / 总组数”。顺序操作时，点击“核对并继续”会保存本组并自动跳到下一组。已有练习记录时，可用“当前对照”重新选择需要演示的组，不必清空旧记录。
  3. 本组上方显示的参数需要手动调整；其他固定参数自动载入。下方“自由调参 · 更多图形”可以核对其余参数。数字框输入纯数字，例如0.2，不在参数控件中加单位。
  4. 出现“先估计读数”时先填估计，再点“提交预测并查看图形”。进入读数后可继续调参，图形实时更新。完成该组前必须回到指定参数。原信号、方程或基准脉冲用于支持预测。
  5. 点图形上的点显示游标，横轴是时间或频率，纵轴是高度、幅度比或响应值。读脉冲高度时看纵轴。显示时间按合适精度读取；读数框可填1、1s或1秒。特殊的平均窗0.02/0.08 s、采样周期和最短脉宽1.61 s仍应保留题目需要的精度。
  6. 若有系数模板，先填完模板，再点“核对并继续”。下表中的参考数值保留六位便于教师复现，课堂按对应读数容差判断。
  7. 最后一组保存后进入“写结论”，结合自己的数据解释。实验三还要填写推导。点“完成自查”，这是练习完成状态；正式分数由独立的“计分验收”产生。

课堂讲解：每一步看哪里、怎么看

  1. 第 1/4 组 · 原信号

    看图：主图画原三角脉冲；峰值在 t=1 s、高度 1，支撑区间为 0 到 3 s。

    怎么读：点击峰值附近的曲线，读横轴和纵轴两个数值，不要把峰值高度读成支撑宽度。

    讲解结论：先固定一个关键点，后面所有变换都看它映射到哪里。

  2. 第 2/4 组 · 压缩 a=2

    看图：实线是压缩后的当前波形，虚线保留原信号对照。

    怎么读：峰值移到 0.5 s，高度仍为 1，支撑终点从 3 s 移到 1.5 s。

    讲解结论：时间轴被压缩到原来的一半，幅度不变。

  3. 第 3/4 组 · 组合 2f(2(t−1))

    看图：主图同时显示原信号和当前结果。

    怎么读：峰值时间为 t=1+1/2=1.5 s，峰高为 2，支撑宽度为原来的 1/2。

    讲解结论：先做时间压缩，再平移结果，幅度单独乘在纵轴上。

  4. 第 4/4 组 · 窄脉冲 Δ=0.2 s

    看图：切到等面积窄脉冲模式，只观察窄脉冲的宽度和高度。

    怎么读：横轴宽度为 0.2 s，纵轴高度为 1/0.2=5，面积仍为 1。

    讲解结论：面积固定时，脉冲越窄，高度必须越高；这是近似冲激函数的直观含义。

L1-2 · 黑箱系统辨识

打开本任务工作台

课堂讲解：每一步看哪里、怎么看

下面是教师带看顺序；使用“当前对照”的任务按组编号对应，黑箱、诊断和卷积任务按页面站点顺序对应。先让学生指出曲线和读数，再解释为什么。

  1. 步骤 1/4 · 发送基准脉冲

    看图：每台黑箱先用虚线输入、实线输出对照。

    怎么读：读输出高度、输出起点和输出宽度；输入高度 1、从 1 s 开始、持续 1 s。

    讲解结论：基准测试只建立参照，不能单独认出模型。

  2. 步骤 2/4 · 幅度加倍

    看图：在基准图上把输入高度从 1 改为 2，比较同一纵轴下的输出高度。

    怎么读：输出高度变为 2 说明仍是线性放大；变为 4 说明经过了平方；不能只看曲线形状。

    讲解结论：线性要求输入放大 2 倍时输出也放大 2 倍，平方器会给出非线性的反例。

  3. 步骤 3/4 · 延后 1 秒发送

    看图：把输入起点从 1 s 移到 2 s，输出仍画在同一时间轴上。

    怎么读：比较输出相对基准延后了多少：延迟系统延后 1 s，时间压缩系统只延后 0.5 s。

    讲解结论：时不变要求输入平移多少，输出也平移多少；平移量不一致就是有效反例。

  4. 步骤 4/4 · 三台综合辨识

    看图：三行测试记录会同时列出输出高度和输出起点。

    怎么读：先用基准建立图形，再用幅度加倍和延后测试逐项排除候选，最后才选模型。

    讲解结论：不同黑箱的候选顺序会打乱；一次测试吻合不足以证明性质普遍成立。

任务：用三个测试认出未知系统

黑箱 A、B、C 各自独立工作，三种模型各出现一次。每台显示一个正确模型与两个干扰模型，并打乱顺序。干扰项从幅度放大、衰减、原样通过、幅度加常数、反相、提前、延迟、时间拉伸、立方等候选中抽取，不再固定显示同样的三个选项。学生需根据本台证据辨识；学生任务说明不提前限定正确模型的范围。

每台黑箱按同样的顺序操作

  1. 点击“发送基准脉冲”。输入高度为 1，从 1 s 开始、持续 1 s；图中虚线为输入，实线为输出。
  2. 点击“幅度加倍”。只把输入高度从 1 改为 2，比较输出高度是否也加倍。图的纵轴固定，平方器的输出会明显从 1 变为 4。
  3. 点击“延后 1 秒发送”。从同一基准出发，只把输入起点从 1 s 改为 2 s，输入高度仍为 1。比较输出比基准延后了多久。
  4. 三行输入输出记录自动保存。先选择“幅度加倍后的输出高度”和“输入延后 1 秒时，输出比基准延后多久”，再选择符合观测的模型，点击“核对观察与辨识”。两项观察与模型均正确才完成本台。选错会提示重看哪项证据，选对后揭示公式与系统性质。
  5. 点击“测试下一台黑箱”，完成 A、B、C 三台。每台的三个候选重新组合，即使正确模型与前一台相同，也需要自己的三次测试与观察依据。学生可以回看测试；模型、候选及选项顺序随记录保存，刷新后保留。
  6. 三台均辨识后查看自动汇总，点击“保存辨识结论并完成实验”。

题库按同一知识点、难度与分值出题，随机参数和部分概念题变化；不同同学可能抽中相同参数，不保证全班唯一。刷新会继续当前试卷；同一浏览器标签页刷新会保留填写草稿，正式成绩以服务端提交记录为准。

七、看成绩、反馈、结束课程

  1. 教师在“实验验收”点击对应实验的“样题与成绩”，再点“刷新成绩”。学生姓名旁为本实验总分。
  2. 展开学生，再查看四项任务的操作/5、独立验收/15、规律/5。展开“第1次验收”或“第2次验收”可核对原题、学生答案与逐项评分。
  3. 需要人工更正时，展开“更正本任务成绩”，在“更正后的分数（0–25）”填新的任务总分，例如23；“更正理由”输入具体原因，例如“课堂复核确认读数录入失误，补记2分”。点“保存更正记录”。原自动分、原试卷和历次更正均保留。
  4. 下课需临时暂停学生操作时，关闭上方对应“实验开放”开关；已保存记录保留，再开启可继续。
  5. 要结束正式验收时，点击对应发布的“关闭验收”，或等待截止时间。关闭后不能提交，并向学生开放已提交试卷的解析；查看过解析的学生，即使之后重新开启，也不能再验。务必在确认收卷后关闭。
  6. 练习材料备份：学生进“我的实验记录”，选择本次实验，下载JSON、打印PDF。打印时浏览器目标选择“另存为PDF”，保存为“学号_姓名_实验1.pdf”；JSON可保存为“学号_姓名_三次实验记录.json”。练习PDF与JSON不是正式成绩来源，正式成绩在验收页查看。
  7. 需要编程教学时，另行打开“学习实验室 → 学习工具 → Python 编程资源”；不做Python不影响本实验100分。
  8. 共用电脑退出账号，核对已保存状态后结束课程。

Python 编程选做：具体操作

  1. 主实验不要求安装 Python。编程选做统一从“学习实验室 → 学习工具 → Python 编程资源”进入，实验任务内不再嵌入代码编辑器。
  2. 选择对应任务的示例代码，手动设置需要比较的参数。修改一处表达式或参数，再运行并比较变化；代码和结果单独保存，不自动写入实验记录。
  3. 需要本地运行时，从学习工具的 Python 资源页下载完整资源包，安装 Python 3.11+，按资源包 README 安装 requirements.txt，然后运行对应 .py 或打开 .ipynb。
  4. 源代码、Notebook、图形和 CSV 可另交学校教学平台。代码运行次数不计分，Python 不进入每次实验的100分。
