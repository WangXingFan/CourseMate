## 查看与复用

- `index.html`：本地候选画廊，支持打开每张原图。
- `contact-sheet.jpg`：六款并排比较的总览。
- `prompts.json`：完整英文提示词、输出规格与设计说明，可用于复现与修改。
- `generation-status.json`：逐个记录实际调用的模型、完成状态和图片尺寸。

六张原始候选均为 **1254 × 1254 白底 PNG**。请求参数为 `1024x1024`，接口实际返回 `1254x1254`；保留接口原始图片，不作缩小或重绘。它们是 AI 生成的位图概念稿；不将其标记为 SVG、矢量稿或已完成商标检索的定稿。

执行方式：当前环境无内置图片生成工具，使用已安装 `gpt-imagegen` 技能的 `scripts/generate_image.py`，通过本机配置的兼容 Images API 调用指定模型。凭据不保存到本目录。
