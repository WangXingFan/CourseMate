## 1. 问题诊断

### 1.1 观察步骤大多是在抄答案

观察阶段页面同时显示可供计算好的指标，要求学生填的那个读数就在旁边。举例：

| 任务 | 要求填写 | 同一屏指标里已有 |
|---|---|---|
| L2-2 步骤 width0/1/2 | 第一正零点 | 指标「第一正零点 = 1/T Hz」 |
| L1-2 linearity/shift 步骤 | 最大绝对差 | 指标「最大绝对差 = 0 / 1」 |
| L1-4 overlap 步骤 | 乘积积分值 | 指标「乘积积分值」 |
| L2-1 harmonic 步骤 | 合成最大值 | 指标「合成最大值」 |
| L2-3 cutoff 步骤 | 是否通过（passed） | 指标「100 Hz 幅度比 / 1000 Hz 幅度比」 |
| L3-2 ninety 步骤 | 找 90% 时刻 | 指标「数值 t90」 |

### 1.2 预测和结果没有形成对照

预测是一句自由文字，之后不会和实测值并排出现，认知冲突无法发生。

### 1.3 一半任务重复同一个一阶系统

L1-3、L1-4 (r*h)、L2-3、L3-2、L3-3、L3-4 都使用 y′+y=x（或τy′+y=x）；
三次实验里没有二阶系统、振荡、极点位置和稳定性判断。

### 1.4 设计题选项范围太窄

L2-3 指标（100 Hz ≥ 0.85，1000 Hz ≤ 0.25）的可行截止频率约为 161–258 Hz；
三个候选 100、200、500 里只有 200 落在范围内，更像查表而非设计。

## 2. 改版方案（A–F）

### A. 隐藏答案、加数值预测（阶段一；纯展示层，不动引擎）

**目标**：让学生先估计，再测量，看到偏差时有明确落差感。

**改动点**：
1. `virtual-lab-flow.ts` 的每个步骤加可选字段 `hiddenMetrics?: string[]`，列出观察前需隐藏的指标标签名称。
2. `native-lab-task.tsx` 的观察阶段：
   - 在显示图形和指标之前，先显示一个数值估计输入框（`predictedValue` 字段）。
   - 学生填入预测后，图形和指标正常显示（游标可读），同时在观察输入框旁边展示「你的预测 / 实测参考」对比。
   - 偏差超过 20% 时，在结论区提示「与预测有较大差异，可以说明修正依据」。
3. 各任务主要保留 3–4 组有区分度的对照；图解卷积保留 5 组，覆盖两类卷积。

**各任务精简方案**：

| 任务 | 原步骤数 | 保留步骤 | 说明 |
|---|---:|---|---|
| L1-1 | 8 | original · compress · combine · pulse1 | 平移并入组合变换；反转和其他窄脉冲宽度改为选做，0.5 s 脉冲作为调参基线 |
| L1-2 | 6 | linear1 · shift2 · shift0 | 保留平方系统非线性反例、时变系统反例和增益系统时不变对照|
| L1-3 | 4 | zeroInput · zeroState · total · lower | 不变 |
| L1-4 | 9 | overlap1 · overlap2 · overlap4 · response1 · response3 | 各保留 2–3 组代表性时刻 |
| L2-1 | 4 | harmonic1 · harmonic2 · harmonic3 | 对应 K=3、7、15；K=1 改为选做背景参考 |
| L2-2 | 5 | width0 · width2 · shift · amplitude | 去掉中间宽度，保留跨度最大的对比 |
| L2-3 | 3 | cutoff0 · cutoff1 · cutoff2 | 不变（等待阶段二改指标）|
| L2-4 | 4 | sample0 · sample2 · candidate | 去掉 25 Hz 步骤（无混叠，冗余）|
| L3-1 | 6 | exponential1 · pulse · delayed | 去掉多余的 a 值对比 |
| L3-2 | 3 | initial · one · ninety | 不变 |
| L3-3 | 3 | initial0 · initial1 · initial2 | 不变 |
| L3-4 | 5 | width0 · width2 · refine | 去掉 width1/width3（中间值，预测容易推断）|

**hiddenMetrics 映射**（举例，建设完整列表时对照 core.mjs 的 metrics.push）：

| 步骤 key | hiddenMetrics（标签精确字符串）|
|---|---|
| original / compress / combine / pulse1（L1-1） | `"峰值时刻"` / `"支撑终点"` / `"峰值时刻"` / `"脉冲高度"` |
| linear1 / shift2 / shift0（L1-2） | `"最大绝对差"`、`"本组试验"` |
| overlap1 / overlap2 / overlap4 / response1 / response3（L1-4） | `"乘积积分值"` |
| harmonic1–3（L2-1） | `"合成最大值"` |
| width0 / width2（L2-2） | `"第一正零点"` |
| shift（L2-2） | `"f=0.25 Hz 相位"` |
| amplitude（L2-2） | `"X(0)"` |
| cutoff0–2（L2-3） | `"100 Hz 测量幅度比"`、`"1000 Hz 测量幅度比"`、`"双项指标"` |
| ninety（L3-2） | `"数值 t90"` |
| width0 / width2（L3-4） | `"测量峰值"`、`"理论峰值"`、`"测量峰时"` |

结论页显示已保存的预测读数与学生实测值并列对照。对超出 20% 的数值差异及判断题不一致项提示学生说明修正依据；旧记录未带预测字段时仍按原有试验记录显示。

### B. L1-2 系统性质检验（阶段二）

**目标**：考查"能不能构造反例"，而不是"能不能读出 0"。

**新系统集合**（共 5 个，含典型误区）：

| ID | 系统 | 线性 | 时不变 | 容易误判原因 |
|---|---|---|---|---|
| `affine` | y = x + 1 | 否 | 是 | 看起来像线性放大 |
| `timescale` | y = x(2t) | 是 | 否 | 线性但时变（学生常反推错）|
| `delay` | y = x(t−1) | 是 | 是 | 对照组 |
| `integrator` | y = ∫₋∞ᵗ x dτ | 是 | 是 | 积分器容易被误认为非线性 |
| `square` | y = x² | 否 | 是 | 保留现有 |

**引擎改动（core.mjs）**：
- `L1-2` 的 `kind` 参数的 `options` 改为 `["affine","timescale","delay","integrator","square"]`。
- 为 `affine` 新增线性/时不变检验逻辑；`timescale` 的时不变检验需要对比 `y(x(t−d))` 和 `y(x)(t−d)`。
- `L1-2` 的 answers 字段加 `evidence` 字符串（学生写反例的输入参数组合，engine 复算验证）。

**输入与记录**：统一采用因果 step、pulse、exp、sin，避免全时间常数积分不收敛。参数记录严格核对并复算。旧 kind `gain` → `delay`、`varying` → `timescale` 只用于新默认设置；旧试验完整归档，不能把不同模型的旧读数解释为新结果。appVersion 升到 1.1.0。

### C. L2-3 收紧为「一阶做不到」的设计题（阶段二）

**目标**：学生先发现一阶滤波器无论如何选参数都无法同时满足两个指标，
再找满足指标的最低 Butterworth 阶数，观察阶数对滚降速率、相移和延迟的影响。

**新指标**（以一阶 H(j2πf) 推导可证明不可行）：
- 有用分量（100 Hz）幅度比 ≥ 0.95
- 干扰分量（1000 Hz）幅度比 ≤ 0.05

一阶低通在这两个约束下无解（由 `|H|=1/√(1+(f/fc)²)` 直接推导，任何 fc 都不能同时满足）。
满足的最低阶为 n=2，可行 fc 约 174.43–223.75 Hz，200 Hz 可达标。二阶 316 Hz 不满足干扰幅度约束；它仅作为设计步骤的初始候选。

**引擎改动**：
- `L2-3` 新增 `order` 参数（select：1、2、3）和对应的 n 阶 Butterworth `|H(jω)|=1/√(1+(ω/ωc)^(2n))`。
- `L2-3` 的 answers 新增 `minOrder` 字段（学生填最低可行阶数）。
- 指标从 spec JSON 里的两个数值改为新阈值。

---

### D. L2-4 加入可听混叠（阶段二）

**目标**：把「同一组采样点对应不同频率」这个抽象概念变成可听见的体验。

**改动点**：
- 将 L2-4 的演示信号频率扩展到音频范围，提供一个「高频试验」模式（例如 3 kHz 正弦，用 4 kHz 采样，混叠频率 1 kHz）。
- 在引擎里暴露 Web Audio API 调用接口（`lab.playAudio(samples, sampleRate)`）。
- `native-lab-task.tsx` 加一个「播放」按钮，只在支持 AudioContext 的浏览器里显示。
- 结合 L2-3 的输出：在 L2-4 的高频模式里，增加一个步骤让学生先接入 L2-3 求出的抗混叠低通滤波器，再采样，比较混叠幅度的衰减（固定播放增益，不作归一化）。

### E. L3 合并并新增二阶极点任务（阶段二）

**目标**：补上三次实验里最大的知识断层——s 平面极点位置与时域/频域行为的对应。

**具体调整**：

1. **L3-2（零状态）和 L3-3（初始条件）合并**：两者都是 `y′+ay=Au(t)`，唯一差别是初值是否为零。合并为一个任务：先求零状态，再用同样的微分变换处理非零初值，共 5 个步骤（对照现有两个任务的各 3 步）。
   - 保留任务 ID `L3-2`（内容扩充），原 L3-3 材料归档，兼容试验合入 L3-2；L3-3 编号用于新二阶任务。

2. **L3-3（新）= 二阶极点设计**：
   - 系统 `y″ + 2ζωₙy′ + ωₙ²y = ωₙ²u(t)`，学生在可视化 s 平面上拖动一对共轭极点（改变 ζ 和 ωₙ）。
   - 步骤一：欠阻尼（ζ=0.3）vs 过阻尼（ζ=1.5）阶跃响应对比，观察超调和振荡。
   - 步骤二：把极点拖到右半平面（ζ<0），观察发散。
   - 步骤三：设计题——选 ζ 和 ωₙ，使超调 ≤ 15%、调节时间（2% 误差带）≤ 3 s。
   - 步骤四：把设计出的极点和频率响应叠加显示，连接频域到时域。
   - 复用 `pole-zero-plot.tsx`；answers 里新增 `zeta` 和 `omegaN` 两个字段。

3. **记录迁移**：旧 `L3-3` 记录（含 `initial=0/0.5/2` 的 params）迁移为 L3-2 的 initialCondition 步骤；新 L3-3 任务新建空白记录。

**引擎改动**：
- `L3-3` 任务名称和参数全部替换（`zeta`、`omegaN`、`measureTime`）。
- `L3-2` 扩充 answers 字段（加 `b0` 初始项系数）。
- `appVersion` 升到 `1.1.0`，迁移逻辑读取旧 `L3-3` params，写入 `L3-2` 的相应步骤，新 L3-3 用默认值填充。

### F. 跨实验心电信号主线（阶段三）

**目标**：以同一条合成心电连接卷积、频域滤波与 s 域零极点分析。

**信号**：完全本地、确定性的 P/Q/R/S/T 高斯分量，每秒一搏，幅度归一化；加入 0.02sin(2π5t)，污染输入再叠加 0.2sin(2π50t)，t<0 为零。各高斯分量 (幅度, 周期内中心, 标准差) 为 (0.12,0.2,0.04)、(−0.15,0.37,0.012)、(1,0.4,0.012)、(−0.25,0.43,0.012)、(0.3,0.65,0.07)。原稿的 Dower 名称不适用于波形合成，已修正。

- L1-4 保留三个矩形重叠对照，将两组 r*h 改为 W=0.02/0.08 s 的心电因果滑动平均。在 t=0.41/0.44 s 读输出，同时保留翻转平移、乘积面积和完整输出图。解释 W/2 线性相位延迟，区分 R 峰形变。
- L2-3 先用一阶低通 fc=2/40 Hz 对照，要求 R(10)≥0.95、R(50)≤0.05，证明截止频率上下界没有交集。再设计 H(s)=(s²+ω₀²)/((s+α)²+ω₀²)，ω₀=2πf₀。中心50 Hz、α=10 s⁻¹可行，最低二阶；比较α=60的宽陷波。幅度比由独立正弦探针复算，心电输出用于检查整体形变。
- L3-3 对同一陷波分析零点±jω₀、极点−α±jω₀、因果ROC与非冲激暂态。比较α=5/60/−10，在设计步骤接入 L2-3 最近保存的达标方案，频响步骤复用本任务设计；拖动极点改变中心与α。α<0时H(jω)仅是代数截面，α=0约消为H=1且不抑制干扰。
- L2-4 保留独立 Butterworth 抗混叠低通，解除从 L2-3 复制参数；50 Hz 心电陷波不能代替音频采样前低通。

模型集中在 `phase-three.mjs`，复用现有工作台及零极点图。学生指导书、评分设计、教师指南、双语题目、Python脚本/Notebook/ZIP与参数起步代码同步。正式自动评分仍未实施。

教师课堂试用与教学价值验收仍需在真实教学环境完成；本轮按用户授权完成实现与技术验证，不代替课堂验收。
