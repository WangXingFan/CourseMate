# 数据统计

教师和管理员从侧栏「数据统计」进入 `/analytics`。教师只能查询本人班级；管理员和超级管理员可查看全站，也可选择某个班级。学生无法读取统计接口。

## 可视化

- **访问与资源**：近 7、30、90 天的访问次数趋势，折线图 / 柱状图切换，资源类别占比、资源排行、班级访问次数和每日明细。每次进入或刷新页面都计一次，同一账号重复访问分别累计。
- **作业**：选择作业库中的某份作业或全部作业，按班级查看应交、完成、未完成份数，切换完成比例、平均分、分数分布。
- **实验报告**：选择实验一、二、三或全部实验，按班级查看应交、进行中、完成、未完成份数，以及完成比例、平均分、分数分布。
- **预习题**：选择已发布的课前预习测和课程小节，查看应答、已答、答对、答错次数，切换小节正确率、答题比例和答题次数图表。

页面提供「统计口径」，支持中英文、浅色 / 深色主题与手机宽度。图表下方保留数据表，访问趋势可展开每日数据。

## 统计口径

访问统计按北京时间（UTC+8）的自然日汇总。访问计数不按账号、IP 或天数去重；同一次网络请求重试使用相同事件 ID，避免重试虚增次数。页面内部筛选、图表切换、后台轮询不新增访问。只记录固定产品页面，不保存查询参数、对话内容、文档内容或任意 URL。

页面访问记录从部署此功能后开始累计。已有的练习、作业、测验、实验记录可直接参与业务统计，不伪造历史访问次数。资源使用统计指对应页面的访问，不表示停留时长或下载次数。

作业、实验、预习题是截至查询时的累计结果，独立于「访问时间」筛选。作业和实验只纳入已经开始的发布任务；预习题只纳入已开放或已截止的 `pre_class` 测验，不纳入草稿或课堂复测。

应交份数按每份任务所属班级当前未删除的学生名单计算；完成份数也只计算该名单内的提交，转出学生不会导致完成比例超过 100%。全部任务合计时，每名学生每个任务计一份。平均分按有效完成份数加权，未完成不按零分计入；没有样本显示「—」。分数段为低于 60、60–69、70–79、80–89、90–100。

实验报告完成以四项任务均有评分提交为准；总分复用现有实验成绩计算，包含操作分、最佳作答结果和教师当前修正值。只完成部分任务计为进行中，不进入已完成报告的平均分和分数分布。

预习题根据发布时保存的题目和答案批改快照按 `LessonID` 归入课程小节。正确率为答对次数 / 已答题次数，答题比例为已答题次数 / 应答题次数。未提交不算答错；同一小节出现在多份预习测中分别累计，合并比例按答题次数加权。

访问记录保存访问发生时的学生所属班级。学生转班后，旧访问保留在原班级；作业、实验和预习题的完成统计使用当前名单。教师只能看到目前归其管理的班级，权限由后端查询限制。

## 接口与部署

- `POST /api/v1/analytics/visits`：登录后的页面访问，身份、班级、记录时间由后端确定。
- `GET /api/v1/analytics/usage?days=30&classroomId=...`：统计数据；`days` 支持 7 / 30 / 90，班级参数可选。
- 新表 `user_usage_visits` 保存访问记录，启动迁移时自动建立；无需第三方统计服务。
- 更新并重新部署前后端后生效；旧客户端不会上报页面访问。

验证包括 SQLite 下的教师 / 管理员 / 学生权限、跨班级隔离、重复访问与请求重试、北京时间边界、带时区的历史记录、作业完成与成绩、实验部分完成与教师修正、预习小节正确率、草稿排除和转班后的名单口径；前端覆盖加权统计及四个页签的筛选、图表、错误 / 空状态和响应式展示。
