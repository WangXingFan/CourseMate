# 班级作业

教师在「班级 → 选择班级 → 作业」选择作业库中的一份作业，预览题目与参考答案，填写开始时间和截止时间后发布。时间输入和展示使用浏览器本地时区，传输与保存使用 UTC。

学生从侧栏「我的作业」进入 `/homeworks`，查看本班作业。未开始时只展示时间和题量，开始后开放题目；提交前显示未完全作答的题数，学生显式确认后可以留空提交，留空部分计零分。提交后立即显示总分、逐题得分与本人答案。每份发布的作业只能提交一次，截止时刻起不再接受提交。教师可以在「成绩与提交」查看提交情况和逐份答卷。

教师可填写原因并延长截止时间，或撤回没有学生提交的误发布作业。截止后可发布答案与解析；发布不可撤销，发布后不再允许延期。已发布解析的错题进入「订正与间隔复习」，订正不改变正式作业成绩。教师更正分数时必须填写原因，保留原始自动评分、答卷以及历次改分记录；正式分数及后续导出采用更正后的分数，已定稿的历史成绩仍保留其原快照。

作业库包含原始 Word 导出的四份作业，每份 10 题、100 分，共 17 道单选、9 道填空、14 道判断。48 处公式图片转成 LaTeX，13 处波形图保留为本地图片。原始题目、答案和分值保持一致；公式内容由导出文件中的源码恢复，缺少源码的公式按原图转录。原始文件的 SHA-256 写入题库，便于追溯。

选择题和判断题按正确选项计分。填空题支持原文给出的多个答案、空格、全角字符、希腊字母 ω、常见 LaTeX 写法，以及数值的等价小数/分数；表达式题按题库列出的常见等价写法匹配。作业 2 的两空题每空 5 分，其余每题 10 分。批改不依赖大模型或外部服务；并非通用符号计算器。

## 答题草稿和待办

学生登录后进入「我的学习」，汇总待签到、未提交课堂活动、作业、未完成实验验收和到期错题复习。任务链接可直达对应任务；未来作业和实验显示开始时间。待办区分待完成、进行中、未开始和逾期未交，并区分未入班、尚未布置任务与当前任务已完成。首页还提供阅读续接和薄弱知识点练习入口。

作业和课堂活动会在输入后自动保存浏览器草稿，刷新或离开页面再返回可恢复。草稿按服务器、账号和任务隔离。作业成功提交后清除草稿，截止未交的草稿保留为只读；教师延期后可以继续作答。课堂活动仍在成功提交或结束后清除草稿。草稿只保存在当前浏览器，不跨设备同步，也不替代正式提交。浏览器禁止存储或存储失败时页面会提示。

入班前已截止、且没有本人提交的作业不再出现在学生作业列表，也不计入教师应交人数和综合成绩平均分。已有提交保留，方便离班后重新加入的学生查阅成绩。

## 按班级下载答卷

教师进入「导出中心」，选择班级，在「学生作业答卷」选择具体发布的作业并点击「打包下载 PDF」。每位学生一份答卷，包含题目、配图、原始作答、逐题评分、正式总分和教师改分记录；未提交单独标注，已退班学生的历史提交也保留。重复发布的同名作业按开始时间区分。支持自定义文件名，所有 PDF 打包为一个 ZIP；详细范围见[班级导出中心](classroom-exports.md)。

## 数据与接口

- 作业库：`backend/internal/domain/classroom/content/homework-bank.json`，编译进后端。答案不会打包到前端静态资源。
- 发布记录：`classroom_homeworks`，保存题目、答案和时间快照。
- 学生提交：`classroom_homework_submissions`，保存原答案、逐题成绩与提交时间；数据库唯一约束阻止重复提交。
- 教师接口：`GET /classrooms/{id}/homework-bank`、`GET/POST /classrooms/{id}/homeworks`、`GET /homeworks/{id}/report`。
- 学生接口：`GET /student/homeworks`、`POST /homeworks/{id}/submissions`。
- 管理接口：`POST /homeworks/{id}/manage`、`POST /homeworks/{id}/students/{student_id}/corrections`。留空提交须传 `confirmBlank: true`。
- 答卷导出：`POST /classrooms/{id}/exports`，传 `kind: "homework_reports"` 和具体发布记录的 `homeworkId`。

重新构建并重启后端会自动建表，四份作业库随程序生效；前端需部署新构建输出。发布操作由任课教师选择班级和时间后完成。

如需从同一格式的原始文件重新生成题库，执行：

```powershell
uv run --with olefile --with beautifulsoup4 python scripts/import-homework-bank.py 'C:\Users\Administrator\Desktop\作业库批量导出(word)'
```

验证覆盖四份作业的评分、填空兼容与部分得分、开始/截止边界、班级权限、重复提交、成绩持久化、学生答案隔离，以及公式渲染和本地波形图。网页验证覆盖教师发布、学生提交、成绩回看和教师查卷，并检查桌面/手机宽度与浅色/深色主题。
