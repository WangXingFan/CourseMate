# 班级作业

教师在「班级 → 选择班级 → 作业」选择作业库中的一份作业，预览题目与参考答案，填写开始时间和截止时间后发布。时间输入和展示使用浏览器本地时区，传输与保存使用 UTC。

学生从侧栏「我的作业」进入 `/homeworks`，查看本班作业。未开始时只展示时间和题量，开始后开放题目；学生答完所有题目后确认提交，立即显示总分、逐题得分与本人答案。每份发布的作业只能提交一次，截止时刻起不再接受提交。教师可以在「成绩与提交」查看提交情况和逐份答卷。

作业库包含原始 Word 导出的四份作业，每份 10 题、100 分，共 17 道单选、9 道填空、14 道判断。48 处公式图片转成 LaTeX，13 处波形图保留为本地图片。原始题目、答案和分值保持一致；公式内容由导出文件中的源码恢复，缺少源码的公式按原图转录。原始文件的 SHA-256 写入题库，便于追溯。

选择题和判断题按正确选项计分。填空题支持原文给出的多个答案、空格、全角字符、希腊字母 ω、常见 LaTeX 写法，以及数值的等价小数/分数；表达式题按题库列出的常见等价写法匹配。作业 2 的两空题每空 5 分，其余每题 10 分。批改不依赖大模型或外部服务；并非通用符号计算器。

## 数据与接口

- 作业库：`backend/internal/domain/classroom/content/homework-bank.json`，编译进后端。答案不会打包到前端静态资源。
- 发布记录：`classroom_homeworks`，保存题目、答案和时间快照。
- 学生提交：`classroom_homework_submissions`，保存原答案、逐题成绩与提交时间；数据库唯一约束阻止重复提交。
- 教师接口：`GET /classrooms/{id}/homework-bank`、`GET/POST /classrooms/{id}/homeworks`、`GET /homeworks/{id}/report`。
- 学生接口：`GET /student/homeworks`、`POST /homeworks/{id}/submissions`。

重新构建并重启后端会自动建表，四份作业库随程序生效；前端需部署新构建输出。发布操作由任课教师选择班级和时间后完成。

如需从同一格式的原始文件重新生成题库，执行：

```powershell
uv run --with olefile --with beautifulsoup4 python scripts/import-homework-bank.py 'C:\Users\Administrator\Desktop\作业库批量导出(word)'
```

验证覆盖四份作业的评分、填空兼容与部分得分、开始/截止边界、班级权限、重复提交、成绩持久化、学生答案隔离，以及公式渲染和本地波形图。网页验证覆盖教师发布、学生提交、成绩回看和教师查卷，并检查桌面/手机宽度与浅色/深色主题。
