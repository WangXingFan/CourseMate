# 交互式输出

本次恢复此前从 DEEIX-Chat 精简掉的 10 类交互式输出，沿用现有学生和教师账号。

## 使用

1. 打开对话页 `/chat`，点击输入框下方的积木图标「输出形式」。
2. 在「交互式组件」中勾选需要的形式。默认选中全部已启用的内置组件；可以清空或恢复默认。
3. 直接描述教学需求。模型会在合适时使用已勾选的组件；如需指定形式，可在问题中明确说明。

| 组件 | 用途 |
| --- | --- |
| 函数图像 | 编辑函数表达式、缩放、拖动和隐藏曲线 |
| 数据图表 | 折线、柱状、面积、散点、饼图等 |
| 交互式计算器 | 拖动参数滑块并实时计算 |
| 测验 / 问答 | 即时判分、解析与分支问答 |
| 数据表格 | 搜索、排序、分页和导出 CSV |
| 决策树 | 逐步选择、返回和重置 |
| 卡片网格 | 分组展示和标签筛选 |
| 指标卡片 | 多指标和趋势展示 |
| 甘特图 | 排期、依赖和里程碑 |
| 文本对比 | 并排或合并查看修改 |

## 适合信号与系统的提问

- 「用函数图像比较 sin(x) 与 sin(2*x)，范围设为 [-2*pi, 2*pi]。」
- 「用交互式计算器展示一阶系统：时间常数 tau 从 0.1 到 5，计算 t=1 时的阶跃响应 1-exp(-1/tau)。」
- 「用数据图表对比这三组采样结果，并说明混叠原因。」
- 「用测验组件出三道卷积概念题，每题给出答案和解析。」

对话中的测验用于自测，交互结果不自动写入课堂成绩或实验记录。正式实验仍从 `/learn/experiments` 进入。

## 接入与更新

前端恢复目录选择、请求参数、流式代码块识别、参数校验和 10 类渲染器。后端恢复组件目录、可见性校验、所选目录的提示词注入，以及 SQLite / PostgreSQL 的表迁移和内置目录初始化。既有组件表按名称同步内置目录，并保留已设置的启停状态。

运行环境需要更新前端静态文件与后端程序并重启服务，随后刷新页面。后端启动时自动初始化目录；普通文本、数学公式、视觉排版提示及 HTML/SVG 预览继续可用。
