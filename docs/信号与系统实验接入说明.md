# 信号与系统实验接入说明

入口：学习实验室 → 算题训练 → 三次完整实验，或 /learn/experiments。

原四章随机闯关入口已替换为三次完整实验，共 12 项任务。旧网址仍能打开对应的完整实验，已有题库作答、错题和概念课程记录保留。

## 学生使用

1. 用原有 CourseMate 学生账号登录，无需新建实验账号。
2. 选择实验一、二或三。每次四项任务，建议每项 45 分钟。
3. 按页面步骤保存预测、改参数、读取图形、保存试验、填写推导和分析，最后自查成果。
4. 姓名与登录账号自动带入，班级可在“我的实验记录”中填写。若登录账号并非学号，提交时按教师要求补充学号；系统不把账号名假定为学校学号。
5. 操作后检查工作台顶部保存状态。记录存入当前账号，刷新或换设备登录后可继续。
6. 下载 JSON 备份全部三次实验；打印报告只包含当前一次实验。按教师要求提交至学校教学平台。

保存失败时保留当前页面，点击重试或下载 JSON。多窗口冲突会停止上传，先备份当前草稿，再选择“载入服务器记录”。导入 JSON 会替换当前三次实验记录，请先备份；当前没有自动合并功能。

## 教师使用

教师或管理员登录后，从实验目录打开“教师开课指南”（/learn/experiments/guide）。

指南覆盖三次实验全部 12 项任务，包含课前准备、10 分钟示范、每项任务的带课步骤、成果要求、教师参考和检查标准，可展开全部并打印。教师演示记录保存在自己的账号下。

参考答案由受权限保护的后端接口返回，学生静态资源中不包含教师指南。学生点击完成只表示完成自查；本次接入未增加集中收作业、批改或自动评分。

## 部署与维护

- 前后端需要一起更新。Go 服务启动时通过现有迁移流程创建 user_learning_virtual_labs 表，不迁移或删除学生账号与旧学习记录。
- 前端静态导出仍为 apps/web/out。学生引擎位于 public/vendor/signal-lab，教师指南嵌入后端，无需部署原独立项目。
- /vendor/signal-lab/index.html 仅允许同源嵌入，其他页面保留原有禁止嵌入策略。反向代理独立设置响应头时，应为此路径保留 X-Frame-Options: SAMEORIGIN 与 frame-ancestors 'self'。
- 账号令牌只在外层 CourseMate 页面使用。实验 iframe 使用不带同源权限的 sandbox，通过来源、窗口和随机标识校验后的消息同步记录。
- JSON 是过程证据，不是可信分数。后端校验任务、参数、范围、单位和大小，并按登录用户隔离保存；修订号阻止旧窗口覆盖更新。
- sessionStorage 仅缓冲当前服务器、账号和标签页的待上传草稿，不读取原独立应用的全局本机缓存。原离线 JSON 可手动导入。
- 修改实验参数定义后，运行 node apps/web/scripts/sync-virtual-lab-schema.mjs 更新服务端校验目录；使用 --check 检查是否同步。

## 验证

验证范围包括数学模型、十二项场景、旧 JSON 迁移、错误导入、账号隔离、真实认证、保存幂等、并发冲突、数据库重开恢复、教师权限及浏览器保存/恢复/导出流程。

常用检查：pnpm --filter @deeix/web check、pnpm --filter @deeix/web test、pnpm --filter @deeix/web build、pnpm api:check。

浏览器集成验证脚本：apps/web/scripts/learning-virtual-lab-smoke.mjs。从仓库根目录运行，设置 PLAYWRIGHT_PACKAGE_JSON 为装有 playwright-core 的包路径；Windows 默认使用已安装的 Chrome，可用 CHROME_PATH 指定其他 Chromium 浏览器。截图与 PDF 保存到 .cache/virtual-lab-smoke。

真实学生课堂试用仍待开展，建议正式开课前按教师指南试讲一次。

## Python 编程复现（2026-10-26）

实验目录、工作台总览与全部 12 项任务已增加 Python 资源入口。每次实验提供一个可独立使用的 `.py` 和同内容的 `.ipynb`，另有完整 ZIP、依赖清单及运行指南，发布在 `/learning/python/`。支持本地 Python 3.11+、VS Code / JupyterLab，或手动上传 Notebook 到学校 JupyterHub / Colab。

每项任务的“Python 编程复现”包含练习要求、可复制的起步代码及下载入口。起步代码采用示例参数，学生需自行改为当前工作台参数。课堂流程补充为：先预测 → 交互测量 → 编程生成信号、修改表达式并计算 → 同参数对照 → 推导分析 → 核对保存。

资源覆盖基本信号生成、时间变换、系统性质、响应分解、连续卷积近似、谐波合成、FFT 与相位、连续低通数值求解、采样与有限 sinc 插值、拉氏数值积分、含初值微分方程和脉宽设计。Notebook 留有预测、修改、数据及解释位置，第三次实验要求学生独立完成解析推导。数值约定与截断误差见资源包 README。

推荐课前完成环境配置，每项 45 分钟可分配为预测 5、交互测量 10、编程修改与比较 15、推导分析 10、保存 5。教师可按班级 Python 基础调整为课后练习，明确必做内容；建议至少抽查一次学生现场改表达式和解释结果。

Python 在学生选择的环境中执行，平台不执行代码，也不自动上传源文件或运行结果。学生可把参数、代码修改及对照结论填写进现有结果分析字段，随账号及 PDF / JSON 保存；修改后的代码、Notebook、PNG / CSV 需自行保存并提交至学校教学平台。

维护时先修改 `apps/web/public/learning/python/` 中的三份 `.py`、README 或 requirements，再运行 `python scripts/build-signal-python.py` 重建 Notebook 与 ZIP；`--check` 校验生成文件。Python 数值回归使用 `python scripts/verify-signal-python.py`，依赖 NumPy、SciPy 与 Matplotlib。静态导出自动包含全部资源，无需增加后端执行服务。
