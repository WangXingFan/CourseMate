# 信号与系统实验接入说明

入口：学习实验室 → 算题训练 → 三次完整实验，或 /learn/experiments。

原四章随机闯关入口已替换为三次完整实验，共 12 项任务。旧网址仍能打开对应的完整实验，已有题库作答、错题和概念课程记录保留。

## 学生使用

1. 用原有 CourseMate 学生账号登录，无需新建实验账号。
2. 选择实验一、二或三。每次四项任务，建议每项 45 分钟。
3. 按“先判断 → 做对照 → 写结论”完成任务。先读本项目标、看原信号并写一句判断，再点击“开始操作”；部分步骤会先要求估计关键读数，提交预测后才显示图形和指标。每组调参、填写实测读数或系数后点“核对并继续”，参数、预测、读数、测量和图形一并保存；结论页并列显示已保存预测与实测。最后回答当前问题，完成自查。
4. 姓名与登录账号自动带入，班级可在“我的实验记录”中填写。若登录账号并非学号，提交时按教师要求补充学号；系统不把账号名假定为学校学号。
5. 操作后检查工作台顶部保存状态。记录存入当前账号，刷新或换设备登录后可继续。
6. 下载 JSON 备份全部三次实验；打印报告只包含当前一次实验。按教师要求提交至学校教学平台。

保存失败时保留当前页面，点击重试或下载 JSON。多窗口冲突会停止上传，先备份当前草稿，再选择“载入服务器记录”。导入 JSON 会替换当前三次实验记录，请先备份；当前没有自动合并功能。

## 分步工作台（2026-10-31）

12 项任务统一为三个阶段。判断前先展示原信号、系统方程与已知条件，保存判断后再展示变换或响应结果；对照阶段每次展示一组操作和主图，需要学生自行选择的参数直接放在当前步骤中。当前变换、卷积对象和系数模板直接用公式呈现。自由调参、其他图形、提示和全部记录按需展开。窄脉冲在信号变换之后单独逐组呈现。

实验一的变换参数由学生调到指定值，每组还需填写一个关键读数；其余任务通过读数、判断、系数或独立调参验证。空白、明显错误的读数、未匹配的系数和未达到目标的独立调参不能进入下一组。结果页显示各组读数，L1-1 默认展开变换与窄脉冲两张简表。第三次实验保留必需推导，结论和推导仍由教师评价。旧记录与 JSON 可以继续导入；没有学生读数的旧试验保留在全部记录中，需要补做核对才计入新流程的完成数。

## 教师使用

教师或管理员登录后，从实验目录打开“教师开课指南”（/learn/experiments/guide）。

指南覆盖三次实验全部 12 项任务，包含课前准备、10 分钟示范、每项任务的带课步骤、成果要求、教师参考和检查标准，可展开全部并打印。教师演示记录保存在自己的账号下。

参考答案由受权限保护的后端接口返回，学生静态资源中不包含教师指南。学生点击完成只表示完成自查；本次接入未增加集中收作业、批改或自动评分。

## 自动评分方案（2026-10-31，设计中）

完整细则见[信号与系统实验自动评分设计](信号与系统实验自动评分设计.md)。本轮交付为设计及文档更新，未实现成绩表、评分接口或班级验收发布；现有前端读数核对不能作为可信成绩。

目标流程为“先判断 → 操作练习 → 计分验收”。每次四项任务，每项操作 5 分（两个检查点 2＋3）、独立验收 15 分、规律判断 5 分（两题 2＋3），共 100 分。预测、补充文字和 Python 不进入这 100 分。练习可反复尝试，不以所有预设保存记录作为验收门槛。

每项默认两次正式验收，每次 20 分，采用新参数、同类难度；任务成绩取操作分加较高的一次整卷验收分，不拼接最佳字段。第一次提交显示得分和错因，主动查看完整解析会经确认结束剩余验收机会。评分容差、部分得分、缺交、截止与重试规则统一冻结在发布版本中。

实施时增加独立的班级发布、操作检查点、题目/答案草稿、提交与成绩记录；服务端出题、复算和计分。客户端上传的 `score`、`passed`、`answerStatus`、`completion.confirmed` 以及 JSON 里的测量均不能直接生成分数。现有 `user_learning_virtual_labs` 和 schema 2 继续存过程材料，旧记录不追溯发分。

先以 L1-1 完成评分样板，再扩展 11 项及班级汇总；正式上线须通过设计文档中的教学、数学、权限和提交一致性验收。开发涉及 HTTP DTO 时按仓库规则生成 API 契约，本轮不修改生成文件。学生指导书与教师指南已同步“设计中”标识及评分摘要。

## 部署与维护

- 前后端需要一起更新。Go 服务启动时通过现有迁移流程创建 user_learning_virtual_labs 表，不迁移或删除学生账号与旧学习记录。
- 前端静态导出仍为 apps/web/out。学生引擎位于 public/vendor/signal-lab，教师指南嵌入后端，无需部署原独立项目。
- /vendor/signal-lab/index.html 仅允许同源嵌入，其他页面保留原有禁止嵌入策略。反向代理独立设置响应头时，应为此路径保留 X-Frame-Options: SAMEORIGIN 与 frame-ancestors 'self'。
- 当前实验工作台为原生 React 页面，每个账号独立创建计算引擎。Python 运行器仍使用隔离环境，服务器不执行学生代码。
- JSON 是过程证据，不是可信分数。后端校验任务、参数、范围、单位和大小，并按登录用户隔离保存；修订号阻止旧窗口覆盖更新。
- sessionStorage 仅缓冲当前服务器、账号和标签页的待上传草稿，不读取原独立应用的全局本机缓存。原离线 JSON 可手动导入。
- 修改实验参数定义后，运行 node apps/web/scripts/sync-virtual-lab-schema.mjs 更新服务端校验目录；使用 --check 检查是否同步。

## 独立 Python 编程资源（2026-11-05 更新）

实验任务内已移除 Python 编辑器、运行环境入口及报告中的 Python 展示。编程练习统一放在“学习实验室 → 学习工具 → Python 编程资源”（/learn/python）。每次实验提供一个可独立使用的 `.py` 和同内容的 `.ipynb`，另有完整 ZIP、依赖清单及运行指南，发布在 `/learning/python/`。支持本地 Python 3.11+、VS Code / JupyterLab，或手动上传 Notebook 到学校 JupyterHub / Colab。

独立页面提供 12 项任务的示例代码、运行结果与下载入口，教师可另行布置编程作业。学生手动设置所需参数；代码草稿和结果不自动写入实验记录。

资源覆盖基本信号生成、时间变换、系统性质、响应分解、连续卷积近似、谐波合成、FFT 与相位、连续低通数值求解、采样与有限 sinc 插值、拉氏数值积分、含初值微分方程和脉宽设计。Notebook 留有预测、修改、数据及解释位置，第三次实验要求学生独立完成解析推导。数值约定与截断误差见资源包 README。

主实验每项 45 分钟仍可按预测 5、操作 25、分析 10、保存 5 安排。自动评分方案上线后建议调整为预测 5、操作 20、计分验收 15、反馈 5；Python 放到主任务后的选做或另行安排的编程课，不因未编程降低主实验满分。另行开设编程作业时，提前试跑环境并公布其课程评价方式。

Python 在独立页面的浏览器隔离环境或学生选择的本地环境中执行，服务器不执行学生代码。已有实验记录中的 Python 字段继续校验、保存并随 JSON 导出，以兼容历史记录；不再提供实验内编辑、运行或报告展示。

维护时先修改 `apps/web/public/learning/python/` 中的三份 `.py`、README 或 requirements，再运行 `python scripts/build-signal-python.py` 重建 Notebook 与 ZIP；`--check` 校验生成文件。Python 数值回归使用 `python scripts/verify-signal-python.py`，依赖 NumPy、SciPy 与 Matplotlib。静态导出自动包含全部资源，无需增加后端执行服务。

## 按班级开放实验（2026-11-04）

教师进入「班级」，选中自己的班级，在「实验开放」中独立开启或关闭实验一、二、三。新建和既有班级的三个开关默认关闭；管理员可查看班级开关，只有任课教师可更改。教师和管理员保留实验预览权限。没有班级的学生不能进入正式实验。

学生实验目录显示开放状态。工作台（含旧链接）及对应 Python 编辑器在进入时、窗口重新聚焦时和每 5 秒检查一次；关闭后卸载操作界面。记录仍可查看、导出和打印。只有全部实验开启时，学生才可整份导入或清空记录。服务端每次保存核对本班开关，拒绝修改已关闭实验，即使同时有其他实验开放。关闭瞬间未保存的修改保留在当前标签页，重新开启后可重试，或下载备份。

数据库使用 `classrooms.lab1_open/lab2_open/lab3_open` 三个默认 false 字段，经现有自动迁移创建。教师接口为 `PUT /api/v1/classrooms/{id}/experiments/{course_id}`，请求 `{ "open": true/false }`；学生查询 `GET /api/v1/learning/virtual-lab/access`。旧版实验迁移允许保留原始归档及规定的转换结果，不能借迁移修改关闭课程的输入。

时间变换读数预测保留原信号图，涵盖平移、反转、压缩和组合参数；结果曲线仍在提交预测后显示。常规时间轴及光标以一位小数显示，并按该精度定位；心电、采样、窄时间窗与最短脉宽任务保留必要精度。数值预测和实测接受匹配单位，如 `1`、`1s`、`1秒`、`1000ms`；时间变换原有 ±0.05 s 的读数容差保留。

验证：前端 check、69 项单元测试、静态构建；班级与学习相关 Go 测试；`learning-lab-access-smoke.mjs` 覆盖三个独立开关、当前页面关闭、直达和兼容链接、原信号参考、带单位读数、光标精度、手机/桌面浅深色界面。试用服务为本地模拟账号，真实部署需同时更新前后端。
