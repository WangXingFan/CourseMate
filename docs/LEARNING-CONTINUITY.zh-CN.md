# 学习续接与巩固

## 学生

- **我的学习**：按状态查看待办，未来作业和实验可提前看到，逾期未交任务保留入口。未入班时提供入班入口；尚未布置任务时可从讲义和自主练习开始。薄弱知识点链接到对应题库。
- **讲义**：支持标题及正文搜索、收藏筛选、恢复上次章节与阅读位置，以及直达该节练习和关联实验。阅读位置和收藏按服务器、账号保存在当前浏览器，暂不跨设备同步。
- **订正与间隔复习**：在 `/learn/progress` 按自主练习、课程练习、课堂活动、作业筛选，查看原作答并重新作答。课堂活动结束后开放；作业需教师先发布解析。快问快答继续使用原有变式复习区。
- **复习安排**：错题初次在一天后到期，到期答对后依次间隔 3、7、14、30 天，完成五轮后结束；答错回到一天后复习。提前练习提供反馈但不会跳过复习阶段。自主练习后来答对不会清除尚未完成的复习安排。
- **AI 求助**：讲义、练习结果、错题订正和自主实验可选择问题，预览附带内容，再带入聊天草稿。用户确认发送后可继续多轮问答；不会自动发送。正式实验验收仍按原规则作答。

订正会增加学习证据并更新可关联知识点的掌握画像，保留原始作业和课堂成绩。作业分数只有教师留痕更正才会改变。

## 教师

在「班级 → 知识掌握」选择薄弱知识点，预览并选取最多 10 道题，确认指定学生和标题后发布巩固任务。默认选中该知识点薄弱的学生，可调整名单。任务仅向所选学生开放，沿用课堂活动的提交、结束和报告功能。定向巩固任务不计入正式课堂表现成绩。

在「班级 → 课堂活动」使用「复制活动」，选择本人管理的目标班级。复制结果为独立草稿，保留题目与答案快照，不携带原提交记录。定向巩固任务需重新确认目标班学生；进入目标班级检查后再发布。

作业延期、撤回、发布解析和改分规则见 [班级作业](HOMEWORK.zh-CN.md)。

## 接口与升级

- `GET /learning/corrections`、`POST /learning/correction-attempts`：查询错题并提交订正，UUID 防止网络重试重复记账。
- `GET /learning/course/search?q=...`：仅搜索已发布讲义，不搜索私有评分答案。
- `GET /classrooms/{id}/remediation-bank`、`POST /classrooms/{id}/remediations`：预览题库并创建指定学生的巩固草稿。
- `POST /quizzes/{id}/copy`：复制为目标班级的独立草稿。
- 学生实验列表增加待完成任务及进行中标记。读取待办不开放解析，也不消耗剩余尝试次数。

重启新后端时现有自动迁移增加作业管理记录、改分历史、解析发布时间，以及课堂活动用途和指定学生字段。旧数据采用默认值，保留原有行为。订正记录复用学习作答表中的独立版本。前后端和生成的 API 契约需一起更新。
