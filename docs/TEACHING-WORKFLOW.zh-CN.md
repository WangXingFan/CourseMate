# 今日课堂与巩固练习

教师进入班级后默认打开「今日课堂」，按「24 小时内截止」「正在进行」「待开始与草稿」汇总签到、课堂活动、作业、巩固练习和实验验收。支持直接进入各管理页，并在当前浏览器记住最近选择的班级；记忆按服务器与账号隔离。某个来源读取失败时保留其他来源的结果，并显示失败原因。

## 从薄弱点布置练习

1. 打开「知识掌握」，选择一个有待巩固学生的知识点。
2. 点击「布置巩固练习」，从该知识点的公开练习库选择 3–5 道题，并勾选需要练习的学生。
3. 填写名称与截止时间后发布。任务保存题目和发布时的掌握状态快照，题库后续变化不会改写已布置内容。
4. 学生从「我的学习」待办或「课堂活动」完成练习。输入保存为当前浏览器的草稿，选择题和数值题由后端批改。
5. 教师在「巩固练习」查看完成名单、发布时的掌握状态、本次答对题数及逐题作答。

每名学生只能提交一次；相同答案重试会返回原结果，避免网络中断造成重复记录。截止后不接受首次提交。仅被选中且仍在本班的学生可访问任务，提交前不返回参考答案或解析。

练习结果写入现有知识掌握记录，不计入课堂小测、作业或综合成绩。报告中的「布置时掌握情况」和「本次答对」分别代表历史状态与本次作答，不是能力提升百分比；同一道题重复出现也不会累计为多道独立掌握证据。

## 数据与部署

新增 `classroom_practice_assignments` 和 `classroom_practice_submissions` 表，后端启动时自动迁移。学生提交与掌握记录在同一个数据库事务中保存。部署需同步更新后端与前端构建。

- 教师选题：`GET /classrooms/{id}/practice-candidates?conceptId=…&locale=zh-CN`
- 教师发布与报告：`GET/POST /classrooms/{id}/practice-assignments`
- 学生任务：`GET /student/practice-assignments`
- 学生提交：`POST /practice-assignments/{id}/submissions`

作业延期、个人补交和成绩定稿规则见 [班级作业](HOMEWORK.zh-CN.md)。

浏览器回归脚本：`apps/web/scripts/learning-teaching-workflow-smoke.mjs`，使用临时 SQLite 后端和实际接口，覆盖教师与学生流程以及桌面/手机、浅色/深色界面。
