# 教师实验管理

教师从侧栏「实验」进入 `/learn/experiments`，在页面顶部选择班级。原班级页的实验开放开关和实验验收页签已移至此处。

1. 在「实验开放」控制实验一、二、三的学生操作入口。教师仍可通过「预览实验」查看实验内容。
2. 在「实验验收」选择实验，设置可选的开始、截止时间并发布。每班每个实验保留一份发布；已发布的验收可以开启或关闭。
3. 点击「提交情况与成绩」，查看学生姓名、学号、完成状态、已提交任务数、当前得分和最近提交时间。支持按姓名 / 学号搜索，按未开始、进行中、已完成筛选。
4. 点击「查看答卷」查看各任务、各次验收和评分详情，保留教师成绩更正功能；教师样题仍可在报告下方查看。

班级报告显示人数、已完成人数、完成比例、已完成平均分和当前全班平均分。图表可选择已完成分数分布、完成状态和各任务提交比例。

完成须实验的四项任务均有评分提交。已完成平均分和分数分布只包含完成者；当前全班平均分使用所有当前班级学生的现有总分，未开始者计零分。统计沿用现有成绩单，包括教师修正。班级报告与「数据统计 → 实验报告」使用相同的完成标准。

实验开放与验收开放是两个独立开关：前者控制实验操作入口，后者控制验收提交。关闭验收或到达截止时间后停止提交并开放已有试卷解析；关闭实验操作入口不主动公开解析。具体规则可在「发布与评分规则」查看。

此次调整沿用现有班级、实验开放和验收接口及教师权限，已有发布、学生提交、分数和更正记录保持连续。学生仍从实验页进入实验；管理员可通过「数据统计」查看全站统计。
