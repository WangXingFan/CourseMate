# 题库与同知识点前后测

## 目标与题库边界

- 快问快答从12道扩至80道，四个主章节各20道；每轮从所选章节抽10道，不重复，限时90秒。
- 复习变式从24道扩至160道，每道基础题两道，改变情境、数值或表述，不改变核心知识点。
- 现有 156 道课程配套题保留：52 节课 ×（课前预习、课中练习、课后巩固）。其中包含 35 节主课和 17 节附录。
- 每节课另配一道同知识点复测题，共52道，课程题合计208道。课中、课后原题不自动当作等价复测题。
- 快问快答排行榜按本版题库隔离，旧版短轮次的分数不与新版10题轮次混排，个人历史保留。

## 教师使用流程

1. 选择一节课，创建一道预习题，检查题目后发布。
2. 学生独立作答；教师查看提交率、正确率、各选项人数及未交名单。
3. 关闭预习测验，针对主要错误讲解或组织讨论。
4. 从该测验创建关联的复测草稿，检查同知识点变式后发布。
5. 关闭复测，在同一份报告中查看前后变化。只有两次均提交的同一学生进入配对正确率；另列仅前测、仅后测、两次未交人数。
6. 对“错→对”学生安排延迟练习，确认迁移和保持；“对→错”“错→错”学生继续诊断。一次答对只表示本次作答正确，不直接宣称已掌握。

默认推荐一次一个知识点；兼容已有最多 10 道题的课堂小测。题目、答案和关联关系在创建时保存快照，后续题库更新不改变历史成绩。

实际入口为「班级 → 课堂活动」：新建预习测 → 选小节（可预览答案和对应复测）→ 保存草稿 → 发布 → 截止 → 创建同知识点复测 → 核对题目 → 发布 → 截止 → 统计与抽人。

每份预习测最多创建一份关联复测；重复点击返回同一份。创建复测后预习测不可重新开放，避免前测数据随复测结果改变。复测未截止时报告标为临时统计。新旧题快照均支持关联复测；旧快照没有变式时，创建草稿使用当前该小节的已审读变式。

例如采样知识点：预习问“基带带限信号的通用安全采样条件”；复测给出最高3 kHz、选项3/6/8/1.5 kHz，要求选择满足严格条件的采样率，正确为8 kHz。前者测条件识别，后者测条件应用，避免只是记住同一道题的选项位置。

报告以稳定学生ID和知识点ID配对，而不是姓名、学号排序或题目位置。分别列出两次均提交、仅预习、仅复测、两次均未交；已离班但交过卷的学生保留在历史配对名单。正确率变化使用百分点，零配对样本显示“—”，不计算虚假的提升率。

## 本次核验结果

- 原12道快问快答与24道变式的答案位置保留；修订采样阈值、半波反对称、双边带AM、标准一/二阶响应及单虚轴极点的适用条件。
- 原156道课程题逐题核对，63道数值题通过独立公式复算；未发现数值评分键不匹配。补严Welch平均的比较条件与理想微分器的输入范围。
- 新题校验中英文选项一致性、单选唯一性、章节归属、计算值、变式关联、稳定ID及数学渲染。
- 完整题目、答案与解析见 `QUESTION-BANK-ANSWER-AUDIT.zh-CN.md`；自动测试不能证明所有教学情境下都无歧义，教师可在发布前预览核对。

## 出题与核验规范

- 单选题必须有且只有一个正确选项；干扰项对应常见误解。
- 明确零状态/初始状态、连续/离散、因果性、稳定性、收敛域、单位和变换约定。
- 傅里叶变换采用 `X(jω)=∫x(t)e^(−jωt)dt`，反变换含 `1/(2π)`；频率 `f` 的单位是 Hz，`ω` 的单位是 rad/s。
- 采样题区分奈奎斯特速率 `2f_max` 与一般无混叠重建的严格条件 `f_s>2f_max`。
- 前后测共享知识点标识，变式改变数值、情境或推理方向，并记录解析。
- 自动检查覆盖唯一 ID、章节、选项、答案范围、变式关联、翻译完整性与独立公式计算；自动核验不等于人工专家审定。
