# 课堂表现成绩

已实现：班级 → 课堂成绩；学生在课堂活动页查看自己的最新定稿成绩。导出中心支持课堂成绩独立 Excel 和综合成绩单可选项。阶段权重为课前 30%、课中 40%、课后 30%。

## 评价方式

先根据可追溯的答题证据计算综合原始分，再按本班的百分位换算课堂表现分。两种分数同时保留：原始分解释学习表现，换算分表达班内相对位置。

目标是有效参评学生的成绩近似正态分布。百分制、有并列分和未参与学生时，不能保证全班成绩严格正态；不能为了凑人数比例，拆开同分或给未参与者自动补分。

## 综合原始分

所有维度先计算为 0–100 分：

| 维度 | 建议权重 | 计算依据 |
| --- | --- | --- |
| 三阶段答题质量 Q | 50% | 原始活动的得分比例；课前、课中、课后按 30% / 40% / 30% 汇总 |
| 任务参与 P | 20% | 原始活动的完成比例；同样按三个阶段的权重汇总 |
| 订正与保持 G | 20% | 同知识点原测与复测配对，奖励错题订正和持续答对 |
| 持续参与 C | 10% | 有提交的教学周数 / 有应做任务的教学周数 |

`R = 0.50 × Q + 0.20 × P + 0.20 × G + 0.10 × C`

### 答题质量与任务参与

- 每道题先按“所得分 / 该题满分”归一化，再在阶段内等权平均，避免计算题填空数量更多就天然占更大权重。
- 同一阶段内以“活动 + 题目”为应做单位。完整提交活动后，其题目均算完成；已截止未提交的应做题目在 Q、P 中均计零。这是有意同时体现缺少学习成果和缺少参与。
- 同一题出现在教师明确选中的多次原始活动时，各次均计入；复测通过 `SourceQuizID` 区分，不混入原始活动重复计分。现有复测的 `Phase` 均为 `in_class`，不能仅凭阶段识别复测。
- 老师没有布置某阶段时，对其余阶段的 30 / 40 / 30 权重重新归一；学生自己漏交不移除该阶段。

### 订正与保持

- 只比较系统明确关联的同知识点原测和复测，不能直接把不同内容的课前题与课后题相减当作进步。
- 两次均提交时，每组题以复测得分比例计分：复测全对得到 100，部分正确按字段比例计分。原测答错后改对和原测已会且复测仍会都能得满分。
- 同时展示“错→对、对→对、对→错、错→错”数量，解释改善与保持的来源。这个维度衡量后续巩固成果，不把它包装成独立的能力增长估计，也不额外奖励较低起点。
- 教师布置且已经截止的配对任务，学生缺少任意一次提交，该组计零，不能通过漏交剔除低分。
- 全班未布置有效复测时，G 不适用，其权重按比例分配给 Q、P、C。不能只为没有提交复测的个人重新分配权重。

### 持续参与

- 按北京时间自然周统计；任务归入其截止所在周，有原始应做活动的周才进入分母。
- 该周至少完成一份应做原始活动即视为参与，排除复测；不奖励提前抢交或页面停留时长。
- 此项衡量参与是否分散在教学周期中，任务完成量仍由 P 衡量。只统计一周时，此项几乎没有区分度，报表应显示实际覆盖周数。

## 正态分布换算

建议默认目标中心分数为 80，目标标准差为 8，限制在 0–100 分。这两个参数在本次统计开始前确定，不根据某位学生的结果临时变化。

对有效参评学生按 R 从低到高排序。为了避免极小差值被换算成明显分差，R 四舍五入到整数后用于排名；保留未取整原始分供查阅。同分使用平均名次，不按学号、姓名或提交先后拆分。

令 N 为有效参评人数，r 为从低到高的平均名次：

```text
p = (r - 0.5) / N
课堂表现分 = round(clamp(80 + 8 × Φ⁻¹(p), 0, 100), 1)
```

其中 Φ⁻¹ 是标准正态分布的分位数函数。采用名次中点，避免最末名和第一名落到 0% / 100% 而得到无穷值。

| 班内百分位（越大表现越靠前） | 换算分约值 |
| --- | --- |
| 10% | 69.7 |
| 25% | 74.6 |
| 50% | 80.0 |
| 75% | 85.4 |
| 90% | 90.3 |

这里的 80、8 是目标分布参数，并不保证并列、截断、缺测处理后的实际平均值和标准差恰好等于这两个数。简单做原始分的均值、标准差标准化只会平移和缩放，不能把偏态分布变成正态。

相同原始分在不同班级可能得到不同换算分；全班都学得好时，排位靠后的学生也可能被下调。因此换算分不能单独证明知识达标，报表必须同时显示原始分及其依据。

## 全班覆盖与缺测

- 报表列出统计名单内的全部学生；有应做任务但全程没有提交的学生显示“未参与”，原始分和最终分为 0，不参加正态换算。这是对严格“全班正态”的明确例外。
- 没有任何适用任务的学生显示“暂无评价”，不记零分。新加入的学生不承担加入之前已截止的活动；名单异常、请假或豁免由教师在定稿前核对。
- 有提交但全部答错的学生仍有参与证据，按正常维度计分并参评。不能把他们与从未参与者合并。
- 有效参评少于 10 人，或者所有人的排名原始分相同，建议直接采用原始分，提示本次未进行分布换算；不制造没有证据的区分。
- 只纳入已截止的活动；草稿、尚未结束的活动不进入正式统计。范围按活动截止时间筛选，并明确显示包含的活动。
- 复测维度只使用原测、复测均在本次范围内且均已截止的配对；范围外的数据不悄悄参与本次成绩。

## 页面与保存

入口位于「班级 → 课堂成绩」。老师选择统计日期及活动范围，查看计分规则、实际分布和全班成绩表。

表格显示：学号、姓名、三阶段得分与完成情况、订正与保持、覆盖周数、综合原始分、并列名次、换算分、最终分、状态。点击学生可查看具体活动与答题依据；同时显示漏交和错题订正，不只给一个总分。

老师可以对有明确理由的特殊情况修正最终分，记录原因。修正后保留自动换算分，不重新调整其他学生来恢复正态形状。最终分的实际分布可能因此偏离目标。

预览随数据更新；定稿前使用预览指纹核对数据是否变化，变化后需刷新。点击“定稿并发布”时保存统计名单、活动范围、评分规则版本、目标分布参数、各维度计算依据、自动分及修正记录。之后的转班或新增活动不悄悄改写已定稿成绩。学生仅能查看自己在当前班级的最新已发布成绩和依据。定稿记录不可修改，需要调整时生成新的定稿。日期按北京时间解释。导出中心可选当前累计预览或某份定稿；定稿导出保留该次名单。

## 现有项目支持与实施边界

- 现有课堂活动已记录阶段、发布与截止时间、题目快照、学生答案、字段得分依据和提交时间，足以计算 Q、P、C。
- 同知识点复测已记录 `SourceQuizID`、`ConceptID`，并支持改善、保持、退步、未解决的报告，可复用来计算 G。
- 当前学生关联表保存本次加入时间，但未提供完整的历次转班与适用任务历史；首次统计使用当前名单并核对适用任务，定稿后保存名单和依据。
- 当前记录不能可靠反映发言质量、讨论贡献、实际学习时长或思考投入，不自动生成这些分数。
- 实现复用现有答题记录，新增班级汇总计算、成绩页和定稿保存（`classroom_performance_records`，启动时迁移）；不引入 AI 评判、复杂能力模型或逐题难度拟合。
- 核心验证覆盖阶段权重、未布置与漏交的区别、复测归属、并列名次、未参与处理及班级权限隔离。
