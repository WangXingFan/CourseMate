# 知识掌握与学习画像

学生入口：学习中心 → 学习练习 → 知识掌握（`/learn/mastery`），学习记录页也提供入口。
教师入口：课堂 → 选择班级 → 知识掌握。点击共同薄弱点可筛选学生，点击学生查看个人依据。

## 判定范围

- 默认取全部已批改的专项练习、错题复习、当前课程版本的课程练习，以及已结束的课堂测验，不再按 90 天截断。
- 班级与个人页面均支持开始、结束日期筛选；日期按浏览器本地时区解释，包含结束日期当天。可只填一端，点击“全部记录”恢复默认。班级汇总和学生明细沿用同一范围。
- 课程按小节统计，专项练习按题库主题统计，两者分开呈现，不跨来源猜测等价知识点。
- 章节筛选统一使用课程目录中的完整章名，同章的课程小节与专项练习合并为一个选项；练习仍沿用题库的章节归属。
- “复习”进入对应课程讲义小节；“针对练习”进入知识点答题；原有概念实验或实验工作台链接单独显示为“相关实验”。专项主题与讲义小节的关联维护在 `backend/internal/domain/learning/mastery_links.go`，不改变作答证据归属或评分。
- 每道题仅取最近一次答案。最新题目答错为“需要巩固”；最新题目答对为“正在形成”；最近两道不同题目都答对为“初步掌握”；没有证据为“尚未检测”。同一次提交有对有错时，优先展示错误。
- 课堂数值题读取字段答案，沿用提交时的数值评分规则；所有字段正确才记为该题答对，部分得分仍标为需要巩固。历史数值答卷在下次查询时直接按此规则计算，无需重新提交。
- 最近证据最多展示 5 道不同题目。样本数量和答对数量同时显示，避免将少量答案当成完整能力评价。
- 六周图表以统计截止时间为终点（未指定或指定未来日期时使用当前时间），只计所选范围内的作答次数和正确率，包含重复作答，不是掌握分数。周界使用 UTC。
- 浏览页面、保存实验、提交实验结论不直接作为掌握证据。目前不对实验的自由文本作 AI 能力判断。

## 权限与数据

无需新增数据表。学生接口只使用当前登录账号；教师接口先验证班级归属和当前学生名单。教师可看到本班现有学生的个人练习与复习，但课堂测验只计入本班。仍在进行的课堂测验不进入画像，防止提前暴露答题结果。

- `GET /learning/mastery`
- `GET /classrooms/:id/mastery`
- `GET /classrooms/:id/students/:student_id/mastery`

以上接口均接受可选 `startAt`、`endAt`（RFC3339 时间戳，起点包含、终点不包含）。省略参数即无对应时间边界；无效时间或起点不早于终点返回 400。响应不再返回固定窗口字段 `windowDays`。

页面切换账号、班级或学生时取消旧请求，班级汇总不携带某个学生的答题明细。生产错误经既有 HTTP 错误链记录；解析历史答卷失败时附带记录 ID，便于定位。

## 当前边界

这些状态是基于少量题目的形成性反馈，不代表考试成绩或稳定能力。没有答题记录时保持“尚未检测”。课程知识可回到对应章节复习，检测入口使用教师布置的课堂活动；专项练习支持直接按主题练习。

本地 `127.0.0.1:8080/8081` 是演示服务器，知识掌握数据为模拟示例，实际实验记录单独保留。正式后端从真实作答记录计算。
